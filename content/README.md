# PalmTec blog

Create a new file in `content/posts` for every article. Use the file name for the web address, so `how-to-check-lead-quality.md` becomes `/blog/how-to-check-lead-quality`.

Copy `content/posts/first-post-template.md`, rename it, and change `draft: true` to `draft: false` when it is ready to appear on the site.

Supported Markdown includes paragraphs, `##` and `###` headings, bulleted and numbered lists, block quotes, links, bold text, and inline code.
